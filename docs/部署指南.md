# 新手图文教程（与软件界面一一对应）

> 本教程对应 v0.13.0 的「续火花控制台」。便携版双击 `xuhuohua.exe`；源码版用 `启动续火花控制台.bat`。
> 旧的脚本操作方式已退役（`scripts/` 目录仅保留给开发者排障用）。

## 第 0 步：打开软件

双击图标后，窗口会在几秒内弹出（首次启动要初始化，请耐心等一下，不要狂点）。
如果双击后提示「已经在运行」，看任务栏或右下角托盘。点窗口关闭按钮会缩入托盘；托盘右键可一键续火或退出。

## 第 1 步：登录抖音（只需一次）

1. 点左侧「🎵 抖音」
2. 点「📲 打开扫码登录」→ 会弹出一个浏览器窗口
3. 手机抖音 App 扫码登录
4. **登录成功后软件自动保存凭证并关闭浏览器**，什么都不用按

验证：「抖音」页第 1 步下方变成绿色「✔ 已登录」。

## 第 2 步：填好友昵称（抖音）

1. 点左侧「🎵 抖音」，在好友管理区输入或从最近会话勾选好友昵称
2. 想给多个好友续火，继续添加；昵称要与抖音聊天列表显示一致
3. 点「💾 保存好友」；文字与表情在「💬 话术库」页单独管理

验证：回「🏠 仪表盘」，抖音卡片下方显示「好友：xxx」。

## 第 3 步：演练一次（强烈建议）

「🎵 抖音」页 → 点「🧪 演练（只找好友，不发消息）」。
看「🏠 仪表盘」的「实时动态」：出现「演练 完成（退出码 0）」即通过。
如果失败，去「📋 日志」页第二个框看红色内容（一般是昵称没填对）。
发送与演练默认使用无头浏览器，不会弹出浏览器窗口。调试时可在「⚙️ 设置」切换为有头浏览器；扫码登录始终会弹出可见浏览器。

## 第 4 步：配置 QQ 侧

1. 点左侧「🐧 QQ」
2. 点「▶ 启动 QQ」，之后会依次弹 3 个窗口：
   - 「是否允许此应用更改设备」→ 点**「是」**
   - 一个**黑色日志窗口** → 这是续火花的大脑，**最小化，千万别关**
   - QQ 登录窗 → 手机 QQ 扫码
3. 「好友续火花」区域：勾选**「启用」**、填对方 QQ 号（手机 QQ 点好友头像 → 资料页可复制 QQ 号）、设置发送时间。话术来自共享话术库，每天自动随机
4. 点「💾 保存 QQ 配置」。如果当时 QQ 正在运行，按提示「停止」再「启动 QQ」一次即可生效（不用重新扫码）

验证：保存后 QQ 每天会提前五分钟自动启动引擎，到点发送；完成后会自动收摊。无需整天保留黑色窗口。

## 第 5 步：注册每日定时（抖音侧）

1. 点左侧「⏰ 定时」
2. 时间默认 08:30，点「💾 注册/更新定时」→ 弹「已注册每日 08:30 运行」
3. 注意：到点时电脑需开机联网、保持 Windows 登录且不休眠；睡眠/关机不会补发

QQ 侧保存配置后自动注册任务，不需要在定时页重复注册。

## 之后每天会发生什么

- 抖音：每天按设置时间后台自动发送，默认无头浏览器
- QQ：每天提前五分钟自动启动引擎，到点发送后自动收摊
- 控制台可以关闭；独立任务每 30 分钟检查丢失或路径异常的计划任务

## 常见问题

| 现象 | 处理 |
|------|------|
| 抖音发送失败，日志说找不到好友 | 昵称与抖音聊天列表显示不一致：手机抖音看一眼，改「话术库」重存再演练 |
| 提示登录失效 / 要求验证码 | 「抖音」页重新扫码登录一次 |
| 定时任务没跑 | 检查电脑是否开机联网且未休眠；在「设置」点「立即检查并修复计划任务」。杀毒软件隔离程序或脚本时需手动添加信任 |
| QQ 到点没发 | 检查「启用」、登录态和计划任务；在「日志」页查看失败原因 |
| QQ 每天发的话都一样 | 话术轮换任务每天 00:05 自动换；也可在「仪表盘」点「立即续火花（QQ）」随时发 |
| 电脑重启后 QQ 不发了 | 保持 Windows 登录；先看任务计划程序里的「续火花-QQ启动」，再用设置页自检 |
| 软件打不开 | 杀毒软件可能误删组件：把项目文件夹加入白名单 |

## 云服务器 Skill

「⚙️ 设置」的复制按钮实时读取 GitHub 最新 Release 中的 `xuhuohua-cloud-prompt.txt`；资产不存在时提示先发布。Prompt 保持简短，只提供可信下载入口和不可违背的交互约束，完整步骤以同一 Release 包内的 Skill 为准。云端 Agent 下载并校验 `xuhuohua-cloud.zip`，安装 Skill 后先问用户是否启用 QQ、抖音和各自的北京时间，并建议可选配置企业微信群机器人 webhook。QQ 运行 NapCat Docker v4.18.19，经 SSH 隧道提供仅监听服务器本机的实时二维码页面；扫码后验证持久化，再用 `qq-run.py --session-check` 在不发消息的情况下确认可以自动启动、快登和退出。正式 cron 到点才启动容器，被本机同账号顶下线时主动快登，整批结束或异常后停止容器释放账号，平时不运行 watchdog。抖音默认给用户 noVNC 浏览器链接和 SSH 隧道命令；用户确认登录后保存登录态并关闭临时桌面，演练通过后才注册每日无头 cron。Skill 每天北京时间首次使用时后台静默检查版本，失败继续使用旧版；涉及 Compose 或 cron 变化时仍需在任务空闲时重跑安装脚本。Release 包和离线导出均不含凭证。

## 隐私与安全

- 登录凭证（storage-state.json / QQ 登录态）等于账号密码，存放在本机，请勿外传
- 请勿把 `douyin-auto-fire/artifacts/` 目录整体发给别人求助——里面的 trace 文件含网络抓包（含 Cookie），只发「日志」页显示的文本即可
- 自动化请保持低频（每天 1 次、少量好友），防平台风控

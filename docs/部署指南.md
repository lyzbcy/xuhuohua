# 新手图文教程（与软件界面一一对应）

> 本教程对应 v0.3.0+ 的「续火花控制台」软件界面。打开软件 = 双击桌面「续火花控制台」图标或项目根目录的 `启动续火花控制台.bat`。
> 旧的脚本操作方式已退役（`scripts/` 目录仅保留给开发者排障用）。

## 第 0 步：打开软件

双击图标后，窗口会在几秒内弹出（首次启动要初始化，请耐心等一下，不要狂点）。
如果双击后弹出提示「已经在运行」，说明软件已经开着——看一眼任务栏。

## 第 1 步：登录抖音（只需一次）

1. 点左侧「🎵 抖音」
2. 点「📲 打开扫码登录」→ 会弹出一个浏览器窗口
3. 手机抖音 App 扫码登录
4. **登录成功后软件自动保存凭证并关闭浏览器**，什么都不用按

验证：「抖音」页第 1 步下方变成绿色「✔ 已登录」。

## 第 2 步：填好友昵称（抖音）

1. 点左侧「💬 话术库」
2. 「好友列表」里把示例名字「在这里填好友昵称1」**改成好友在抖音里的昵称**（打开手机抖音看聊天列表，显示什么就填什么；改了备注名就填备注名）
3. 想给多个好友续火，点「＋ 添加好友」继续填
4. 文字话术和表情不用改也能用（每天随机抽一条）；想改随意
5. 点「💾 保存话术库」→ 提示「已保存 ✓」

验证：回「🏠 仪表盘」，抖音卡片下方显示「好友：xxx」。

## 第 3 步：演练一次（强烈建议）

「🎵 抖音」页 → 点「🧪 演练（只找好友，不发消息）」。
看「🏠 仪表盘」的「实时动态」：出现「演练 完成（退出码 0）」即通过。
如果失败，去「📋 日志」页第二个框看红色内容（一般是昵称没填对）。

## 第 4 步：配置 QQ 侧

1. 点左侧「🐧 QQ」
2. 点「▶ 启动 QQ」，之后会依次弹 3 个窗口：
   - 「是否允许此应用更改设备」→ 点**「是」**
   - 一个**黑色日志窗口** → 这是续火花的大脑，**最小化，千万别关**
   - QQ 登录窗 → 手机 QQ 扫码
3. 「好友续火花」区域：勾选**「启用」**、填对方 QQ 号（手机 QQ 点好友头像 → 资料页可复制 QQ 号）、设置发送时间。话术来自共享话术库，每天自动随机
4. 点「💾 保存 QQ 配置」。如果当时 QQ 正在运行，按提示「停止」再「启动 QQ」一次即可生效（不用重新扫码）

验证：保存后把 QQ 页的「停止」→「启动 QQ」走一遍，不报错即可。到点自动发送。

## 第 5 步：注册每日定时（抖音侧）

1. 点左侧「⏰ 定时」
2. 时间默认 08:30，点「💾 注册/更新定时」→ 弹「已注册每日 08:30 运行」
3. 注意：到点时电脑需开着、没睡眠、联网；睡眠/关机不会补发

QQ 侧不需要这步：QQ 页里保持运行的那个程序会自己在配置的时间发。

## 之后每天会发生什么

- 抖音：每天 08:30 后台自动发送（电脑开着即可），无需任何操作
- QQ：黑色窗口开着就会按你配的时间自动发送

## 常见问题

| 现象 | 处理 |
|------|------|
| 抖音发送失败，日志说找不到好友 | 昵称与抖音聊天列表显示不一致：手机抖音看一眼，改「话术库」重存再演练 |
| 提示登录失效 / 要求验证码 | 「抖音」页重新扫码登录一次 |
| 定时任务没跑 | 到点时电脑必须开着。错过可手动点「立即续抖音火花」 |
| QQ 到点没发 | 检查黑色窗口是否开着（被关了就重新「启动 QQ」）；检查「启用」有没有打勾 |
| QQ 每天发的话都一样 | 话术轮换任务每天 00:05 自动换；也可在「仪表盘」点「立即续火花（QQ）」随时发 |
| 电脑重启后 QQ 不发了 | 正常：重启后需打开软件点一次「▶ 启动 QQ」 |
| 软件打不开 | 杀毒软件可能误删组件：把项目文件夹加入白名单 |

## 隐私与安全

- 登录凭证（storage-state.json / QQ 登录态）等于账号密码，存放在本机，请勿外传
- 请勿把 `douyin-auto-fire/artifacts/` 目录整体发给别人求助——里面的 trace 文件含网络抓包（含 Cookie），只发「日志」页显示的文本即可
- 自动化请保持低频（每天 1 次、少量好友），防平台风控

# reference · 上游项目边界

## 我们 vs 上游

```
续火花/（本项目根）
├── douyin-auto-fire/          上游①：抖音主力（unmev，PolyForm Noncommercial ⚠️禁商用）
├── napcat-plugin-auto-tasks/  上游②：QQ 插件（ChaceQC，MIT）
├── DouYinSparkFlow/           上游③：抖音备选（2061360308，MIT）
├── tools/napcat/              上游④：NapCat v4.18.19 一键包（NapNeko，MIT）
└── scripts/ docs/ logs/ ...   ← 本项目自有的全部东西
```

## 更新策略

- 上游①②③ 均为 git clone，可 `git pull`（`检查更新.bat` 一键做）
- 上游④ NapCat 按版本发布 zip，更新 = 重新下载解压 + 重新部署插件 dist
- 我们改上游代码的情况仅限：上游选择器失效等被迫 hotfix —— 改完 `git stash` 保存补丁，防止 pull 冲突

## 备胎切换预案（主力失效时）

1. 症状：`douyin-run-dryrun.bat` 连续多日定位失败 / 上游仓库停更且抖音改版
2. 动作：按 `DouYinSparkFlow/docs/源代码部署说明.md` 起备选（同为 Python+Playwright，环境可复用大半）
3. 话术迁移：把 `config.json` 的 choices 文本抄进备选的配置生成器即可

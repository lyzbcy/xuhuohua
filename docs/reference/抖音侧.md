# reference · 抖音侧（douyin-auto-fire）

> 深入改抖音侧行为前读这个。源码在 `douyin-auto-fire/`（上游仓库，278★）。

## 运行原理

Playwright 驱动 Chromium 打开 `https://www.douyin.com/chat`，用 `storage-state.json`（扫码登录产物）恢复登录态 → 按配置里的好友名在左侧会话列表定位 → 打开会话 → 发消息（文字/图片/原生表情）→ 逐好友循环。

## 关键文件

| 文件 | 作用 |
|------|------|
| `run.py` | 入口；无 `config/accounts.json` 时单账号模式 |
| `app/config.py` | 配置解析；`TASK_CONFIG` 环境变量可指定任务文件 |
| `app/sender.py` | 发送逻辑：文字输入、图片 `set_input_files`、原生表情点击 |
| `app/selectors.py` | 页面元素选择器 —— **抖音改版时要改这里** |
| `app/browser.py` | 启动浏览器；`HEADLESS` 环境变量控制有头/无头 |
| `app/history.py` | 防重复发送的本地记录 |
| `scripts/login.py` | 扫码登录 → 生成 `storage-state.json` |
| `artifacts/run.log` | 每次运行的详细日志（排障第一现场） |

## 配置模型（app/models.py）

```
TaskConfig
 ├─ targets: Target[]          # 每个好友一个
 │   ├─ name: str              # 聊天列表显示名（备注优先）
 │   └─ messages: Message[]    # 依次发送；random 类型 = 抽一条
 ├─ Message.type: text | image | douyin_sticker | random
 │    text:  {"type":"text","content":"..."}
 │    image: {"type":"image","path":"stickers-lb/xx.png"}   # 相对 config.json 所在目录
 │    sticker:{"type":"douyin_sticker","sticker":"比心"}     # 可用: 比心/开心（config/stickers.json）
 │    random:{"type":"random","choices":[...]}               # 不可嵌套
 └─ send_interval_seconds: {min,max}   # 好友间隔随机秒数（拟人）
```

## 多账号

`config/accounts.json` 存在即进入多账号模式，每账号一个 `.env.accountN`（Cookie）+ `config/tasks/accountN.json`（任务）。当前未启用。

## 常见排障

1. **找不到好友**：昵称与聊天列表显示不完全一致；备注名最稳
2. **登录失效**：重跑 `scripts\douyin-login.bat`
3. **选择器失效**（抖音改版）：dry-run 卡在定位 → 看 `artifacts/` 下的截图 → 改 `app/selectors.py`
4. **看详细过程**：`.env` 里临时改 `HEADLESS=false`，能看到浏览器操作全过程

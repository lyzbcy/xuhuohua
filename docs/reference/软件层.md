# reference · 软件层（software/）

> 改软件本体前读这个。技术栈：pywebview（窗口壳）+ 原生 HTML/CSS/JS 前端 + Python 后端。

## 运行机制

```
启动续火花控制台.bat → software/.venv/pythonw.exe main.py
  └─ pywebview 窗口加载 ui/index.html（file 协议）
       └─ 前端 JS 通过 pywebview.api.<方法> 调用 main.py 的 Api 类
            └─ Api 分发到 backend/ 各模块（子进程/文件IO/计划任务）
```

## 模块职责

| 文件 | 职责 | 关键点 |
|------|------|--------|
| `main.py` | Api 桥接类 + 窗口创建 | 加新功能 = 加 Api 方法 + 前端调用 |
| `backend/paths.py` | 全部路径常量 | 从 `__file__` 推导，项目可整体搬迁 |
| `backend/logger.py` | 事件总线 | 三路输出：UI状态栏 / 仪表盘 / `logs/*-software.log`；前端 1.6s 轮询 `get_events(since)` |
| `backend/douyin.py` | 抖音引擎调度 | 子进程调 `douyin-auto-fire/.venv` 的 python；输出逐行泵入事件总线 |
| `backend/login_gui.py` | 界面内扫码登录 | 轮询 `sessionid` Cookie，成功自动保存 `storage-state.json`（5 分钟超时） |
| `backend/qq.py` | NapCat 启停 + 插件配置 | 配置写 `tools/napcat/shell/config/napcat-plugin-auto-tasks.json`；启动时自动同步部署插件 dist |
| `backend/scheduler.py` | 计划任务 | schtasks 封装；任务名 `续火花-抖音`，入口 `daily_douyin.ps1` |
| `backend/updater.py` | 版本/更新 | fetch 比对 → ff-only pull → 依赖同步；失败兜底提示重试 |
| `backend/winproc.py` | 子进程编码安全 | `run_cmd` 双编码解码（GBK/UTF-8），**所有**子进程输出必须走它 |
| `backend/daily_douyin.ps1` | 定时任务静默入口 | 带 UTF-8 BOM；未登录 exit 3；输出落 logs/日期.log |
| `ui/index.html` | 七页面骨架 | 仪表盘/抖音/QQ/话术库/定时/日志/关于 |
| `ui/app.js` | 前端逻辑 | `call(方法, 参数)` 封装；轮询状态 3.2s/事件 1.6s |

## 约定

1. **加后端功能**：`backend/` 写函数 → `main.py` Api 加薄封装 → `app.js` 加按钮和 `call()`
2. **改 UI**：纯静态无构建步骤，改完重启软件即生效
3. **话术库数据模型**：UI 把「好友列表 + 文字池 + 勾选表情」序列化成上游 schema（每好友一个 target，共享一个 `random.choices`）保存前经上游解析器校验
4. **QQ 插件配置**：字段以 `napcat-plugin-auto-tasks/src/types.ts` 的 `DEFAULT_CONFIG` 为准，两边需保持同步
5. **新 ps1 文件必须带 UTF-8 BOM**（PS 5.1 无 BOM 会当 ANSI 解析成乱码）

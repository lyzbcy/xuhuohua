续火花控制台 v0.13.2（Windows x64）

1. 解压整个文件夹，双击 xuhuohua.exe。首次在抖音页点“一键初始化”，完成后扫码登录。
2. 在抖音页添加好友，话术库里设置消息；先点“演练”验证，再注册每日时间。
3. QQ 页首次扫码登录、选择好友和时间并保存；软件会注册提前五分钟启动的每日任务。
4. 抖音发送默认用无头浏览器。需要看浏览器调试时，在“设置”切换成有头模式。
5. 关闭窗口会缩入右下角托盘；托盘右键可一键续抖音或 QQ 火花。

定时运行时软件可以关闭，但电脑必须开机联网、保持 Windows 登录且不休眠。
杀毒软件若隔离程序或任务，请手动添加信任，再到设置页点“检查并修复计划任务”。
云服务器用户在设置页复制 Prompt，云端 Agent 会下载最新 Release 的 QQ + 抖音 Skill 包并询问平台与时间；QQ 发二维码图片，抖音通过 SSH 隧道连接虚拟桌面扫码。离线包可选，包内不含登录凭证。

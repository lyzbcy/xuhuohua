抖音续火花

⚡ 首次使用：初始化引擎（全自动下载，约 5-10 分钟）

缺什么会自动下载什么（Python、抖音依赖、浏览器组件、QQ 引擎），全程无需操作、不弹任何窗口，进度实时显示在下面。可以最小化软件去忙别的，装完会有提示。

⏳ 准备中…
第 1 步 · 扫码登录（一次性）

点击按钮会弹出浏览器，用抖音 App 扫码。登录成功后软件自动保存凭证并关闭浏览器，无需其他操作。

第 2 步 · 管理好友

推荐点「从抖音拉取最近会话」勾选（免手打）；也可以手动添加。规则：勾选添加会与现有列表合并，同名只保留一个；「保存好友列表」后以页面列表为准。名字要和抖音显示的完全一致（含表情符号）。

第 3 步 · 运行

先演练确认好友都能定位到，再正式发送。之后每天由定时任务自动完成。

「补发」用于这种情况：某好友当轮发送中途失败（如页面弹窗干扰），留下了"结果不确定"记录被防重复误挡。点它会清除确认没发出去的残留记录并立即重发一轮；已成功发送的不会被重复发。

QQ 续火花

QQ 引擎（NapCat）

点「启动 QQ」后会依次弹出 2 个窗口：①「是否允许更改」的询问窗 → 点「是」；② 一个黑色日志窗口 → 这是续火花的大脑，请最小化、千万别关，关了 QQ 火花就停了。登录过一次后，以后启动自动快速登录，不用扫码；电脑重启后要回来再点一次「启动 QQ」。

QQ 登录二维码

手机 QQ 扫这个码即可，只需扫这一次，之后每次启动自动快速登录。

🛡️ 放心扫：这个二维码只是让续火花程序在这台电脑上登录你的 QQ，不会在任何别的地方登录，不涉及密码，对你的 QQ 账号没有任何负面影响。

🔊 每日定时提醒（答疑）

        
注册定时任务后，到点时软件可以关闭，但电脑必须开机联网、保持 Windows 已登录且不休眠。QQ 引擎会在发送前五分钟由计划任务自动启动。

        
杀毒软件可能拦截或隔离定时任务、程序或脚本。软件启动时会检查并修复丢失的任务；若程序本身被隔离，请在杀毒软件里手动添加信任，然后重新打开软件。

        

      

    


    

      
云端 Skill

      

        
让服务器接班

        
把部署提示词发给你的云端 Agent。它会引导你选择 QQ 或抖音，设置时间并扫码。之后由服务器到点运行。

        

          
          
        

        

      

      

        
同步当前话术库和表情

        
同步包包含已保存的文字、签名、精选表情原图和勾选状态。把文件交给你自己的云端 Agent 导入，QQ 和抖音会在下次定时使用。

        

        python3 xuhuohua-cloud/scripts/message_policy.py import xuhuohua-library.zip
        

      

    


    

      

        

          
火花是怎么续上的？
像把一张小纸条，按时送给朋友。

          
        

        

          
先装好小纸条
你挑好文字和表情，选定朋友和时间。小助手就有了一只自己的纸条盒。

          
到点响铃
时间一到，电脑或云服务器叫醒小助手。云端接班时，你的电脑可以关着。

          
进门送一张
你扫码授权后，小助手用保存的登录状态，进 QQ 或抖音找到朋友，从你勾选的内容里抽一张发出去。

          
看看送到了没
QQ 会回看聊天记录。抖音会检查发送结果。遇到不确定的情况就记下来，免得再发一遍。

          
送完就收工
云端 QQ 用完就退出。下次如果登录失效，小助手会等你重新扫码。

          
纸条一直由你挑
文字和表情来自你保存的话术库。想换一封，随时去「话术与签名」改。
